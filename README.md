# High-Speed FFT Visualization App

A high-performance web application for real-time Fast Fourier Transform (FFT) visualization and image processing.

## Status: Version 1.0 Stable

This application provides a robust interface for exploring frequency domain representation of images using WebAssembly-powered FFT logic.

## Key Features
- **High-Performance FFT**: Leverages `kissfft-wasm` for fast processing.
- **Interactive Visualization**: Real-time magnitude spectrum display.
- **Drag & Drop**: Easily upload images for analysis.
- **Responsive Design**: Modern UI with a focus on performance and clarity.

## Getting Started

### Prerequisites
- Node.js installed on your system.

### Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.

### Development
To start the development server:
```bash
npm run dev
```

### Build
To create a production build:
```bash
npm run build
```

## How to Use
1. Drag and drop an image onto the uploader.
2. View the FFT magnitude spectrum in real-time.
3. Use the controls to adjust the visualization.
